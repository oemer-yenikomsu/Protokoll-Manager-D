# Benutzerdokumentation

Das **Benutzerhandbuch** ist Teil der Webanwendung und wird mit dem Frontend ausgeliefert.

## Quelle (maßgeblich)

```
frontend/public/benutzerhandbuch/index.html
```

Dort bearbeiten – nicht in diesem Ordner duplizieren.

## Erreichbarkeit

| Umgebung | URL |
|----------|-----|
| Produktion | `http://<Host-IP>:5000/benutzerhandbuch/index.html` |
| Entwicklung (Vite) | `http://localhost:5173/benutzerhandbuch/index.html` |
| In der App | Menü → Benutzerhandbuch |

Details: `EINRICHTUNG.md` (Abschnitt Benutzerhandbuch).
